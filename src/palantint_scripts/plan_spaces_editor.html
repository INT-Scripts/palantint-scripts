Espaces définis

    Aide

    Les zones fermées sans numéro sont détectées automatiquement (Non qualifié). Cliquer dessus pour en faire un couloir, un escalier, etc. Une zone ouverte sur l’extérieur ou sur une autre se ferme avec une cloison, invisible dans le rendu. Vide retire une zone du sol (patio, gaine).

    Touches 1–5 : type · Suppr : retirer · Échap : annuler · molette : zoom · glisser : déplacer.
